# 照片和鸟声识别

开始时说明文件会上传到 Bulbul 云端，按当前会话授权和 harness 的上传要求执行。用户已经同意上传或明确要求使用 Bulbul 云端识别时，沿用授权，不重复询问。附件需要是可读取的本地文件；`file` 使用绝对路径，不支持远程 URL。

先批量查看 `identify_photo` 或 `identify_audio` 与需要的鸟种查询 schema。模型结果返回前，肉眼或听声判断只能作为初步候选，不能提前确定鸟种。结合实际结果及必要的百科特征说明结论；若推翻初步判断，明确更正并解释依据。模型分数不是识别正确率。

## 地点和日期

已知拍摄或录音地点、日期时传入 `latitude`、`longitude`、`captured_at`（`YYYY-MM-DD`），云端运行 Geomodel。地点只有地名时用 `location_search` 解析；有多个合理候选时请用户选择。不猜坐标，不使用今天代替录音日期，不自行计算校准权重。

缺少地点日期仍可先识别，说明返回的地区校准或未校准状态，再按需要询问补充信息。不要为了收齐信息拖延已经可以给出的初步结果，也不能声称已经完成 Geomodel 校准。应用继续本地推理，CLI 不下载模型。

## 文件和声音参数

照片最多 20 MB。声音**完整文件**最多 50 MB、0.5–300 秒；传 `start_seconds`、`end_seconds` 只改变分析选区，不能绕过完整文件上限。超过 5 分钟时先按用户需要截取或拆分文件。

声音支持 WAV、FLAC、MP3、M4A（AAC/ALAC）、AIFF 和 Ogg Vorbis；Opus 先用可用工具转为 WAV。默认与应用相同：3 秒窗口、1.5 秒步长、标准灵敏度、连续确认、高通关闭。只有用户需求需要时才调整参数。

`score` 是原始分数，`rank_score` 用于排序；保留 `distribution_mismatch` 提示及声音时间片段。机器结果按校准分数排序，应用的“最近出现”只改变界面顺序。候选不能自动记作已确认观察；需要比较相似种时，用返回的 `taxon_id` 查询 `species_wiki` 或 `species_detail`。

## 交付结果和失败恢复

先给主要候选、关键识别依据、实际校准状态和仍有的疑点；声音给出有用的时间片段。需要提高把握时说明适合补充的照片角度、录音片段或地点日期。查询参数或保存文件属于辅助工作，最终答复应直接回应“是什么鸟”。

CLI 只对明确未受理、带 `Retry-After` 的 429 最多自动重试 2 次，重试前累计等待最多 20 秒。仍繁忙时按提示等待，不再由 agent 连续重试；网络错误、超时和其他失败不自动重新上传，无法确定是否完成时先检查已有结果。
